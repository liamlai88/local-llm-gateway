## 4. 决策结论（按 ROI 排序）

### 🥇 LoRA 1.5B 本地（实验 #8）— 最强 ROI

- **成本**：¥1.2/月（10K 次/天），即一杯咖啡钱
- **准确率**：100%（窄任务上完胜 turbo）
- **代价**：开发期 25 分钟训练 + 100 条标注样本
- **适用**：分类、抽取、特定格式生成
- **不适用**：开放域问答、多任务、对话

### 🥈 Multi-Agent 混合架构（实验 #9）— 最强通用 ROI

- **成本**：¥90/月（10K 次/天），规则吃掉 80% 流量，LLM 只兜底
- **准确率**：100%
- **优势**：兼具规则的稳定性 + LLM 的灵活性
- **适用**：客服路由、风控、多技能场景

### 🥉 Plan-Execute Turbo（实验 #6）— 复杂任务首选

- **成本**：¥432/月（10K 次/天）
- **准确率**：87.5%（远超 ReAct 62.5%）
- **代价**：3× LLM 调用，延迟翻倍
- **适用**：多步推理、需要规划的任务

### 不推荐: Reflection / GraphRAG / qwen-max

- **Reflection** (#12)：成本 +33%（4 LLM 调用），准确率不增
- **GraphRAG** (#13/15)：4 项 RAGAS 指标都输给 Naive
- **qwen-max**：单次成本是 turbo 的 73 倍，但准确率提升边际（在我做过的实验里没看到必须用 max 的场景）
